# PlanB — Práctica ISW

PlanB es una red social, con aplicación móvil y versión web, para compartir y descubrir **experiencias**: planes completos por una ciudad (lugares, actividades, presupuesto y duración) creados por otros usuarios, en lugar de reseñas de sitios sueltos.

## Estado del proyecto

El proyecto está en fase de definición: la propuesta de producto y las historias de usuario ya están redactadas, y ahora se está documentando la arquitectura y el diseño técnico.

## Documentación

Toda la documentación detallada vive en [`documentacion/`](documentacion/):

* [Propuesta inicial](documentacion/propuesta-inicial.md) — planteamiento conceptual del producto: problema, público objetivo, objetivos, módulos funcionales, modelo de datos, comparación con soluciones existentes, límites de alcance y riesgos.
* Arquitectura — en desarrollo.

Las historias de usuario del equipo están en [`customer-stories/`](customer-stories/).

## Estructura del repositorio

* `documentacion/` — documentación del proyecto (propuesta de producto, arquitectura, decisiones de diseño).
* `customer-stories/` — historias de usuario del equipo, en formato hoja de cálculo (una hoja por historia) y los documentos individuales de partida de cada miembro.
