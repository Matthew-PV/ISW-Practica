# Registro de prompts utilizados en PlanB

## 1. Objetivo

Este documento registra las interacciones con agentes de inteligencia artificial que hayan influido de forma relevante en el análisis, el código, las pruebas o la documentación de PlanB. Permite relacionar la ayuda recibida con las decisiones humanas y con el resultado incorporado al repositorio.

No es un volcado completo de conversaciones. Se seleccionan los prompts que definen una tarea o cambian de forma importante su solución.

## 2. Reglas del registro

- Cada integrante registra sus propias interacciones y responde de que el texto sea fiel.
- Se conserva el prompt con su redacción original siempre que no contenga información sensible.
- Si el prompt incluía un secreto, una cookie, una credencial o datos personales innecesarios, se elimina ese contenido y se indica `[DATO OMITIDO]`.
- Se registra también la intervención humana: qué se aceptó, corrigió o rechazó.
- Se enlaza la historia de usuario y el commit o pull request cuando existan.
- Las entradas se añaden en orden cronológico inverso dentro de la sección de cada integrante: la más reciente primero.
- No se inventan prompts pasados. Las interacciones anteriores se incorporan solo si el integrante conserva el texto o puede aportar un resumen identificado claramente como reconstruido.

## 3. Plantilla de entrada

Copiar esta plantilla en la sección del integrante responsable:

```markdown
### AAAA-MM-DD — Título breve de la tarea

- **Historia u objetivo:** código de historia y criterio, o «sin historia asociada».
- **Agente/herramienta:** nombre y modelo si se conoce.
- **Contexto aportado:** archivos, documentación o estado del proyecto facilitados al agente.
- **Prompt inicial:**

  > Texto del prompt.

- **Correcciones relevantes:** prompts posteriores que cambiaron el enfoque; «ninguna» si no las hubo.
- **Resultado propuesto por la IA:** resumen breve, sin copiar toda la respuesta.
- **Intervención humana:** qué revisó, cambió, aceptó o rechazó el integrante.
- **Comprobación:** pruebas automáticas y manuales realizadas, con su resultado.
- **Resultado en Git:** enlace o identificador del commit/PR; «pendiente» si aún no existe.
```
