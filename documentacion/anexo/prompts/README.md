## Reglas

- Cada integrante registra sus propias interacciones y responde de que el texto sea fiel.
- Se registran los prompts que definen una tarea o cambian de forma importante su solución; no hace falta copiar una conversación completa.
- Se conserva la redacción original siempre que no contenga información sensible.
- Los secretos, cookies, credenciales, contenido de `.env` y datos personales innecesarios se sustituyen por `[DATO OMITIDO]`.
- Cada entrada es corta y sigue la [plantilla](plantilla.md): prompt inicial literal, correcciones que cambiaron el resultado y enlace al commit.
- Las decisiones no se repiten aquí: van en [`decisiones/`](../../decisiones/plantilla.md) y la entrada enlaza a ellas. Lo ocurrido hasta el 2026-10-27 está en el [histórico](../modificaciones.md).
- Las entradas se ordenan de la más reciente a la más antigua.
- No se inventan prompts pasados. Un resumen de una interacción que ya no se conserva se identifica como **resumen reconstruido por el integrante** y no se presenta como cita literal.

El registro aporta trazabilidad, pero no demuestra que el resultado sea correcto. La evidencia técnica sigue siendo el código revisado, el ciclo TDD, las pruebas y la comprobación humana.
