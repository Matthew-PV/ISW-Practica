# La base online compartida pasa de Aiven a TiDB Cloud Starter

**Fecha:** 2026-11-16 · **Historia:** sin historia · **Decidió:** Joaquín, a propuesta de Claude

- **Contexto:** el servicio de Aiven dejó de existir: su host (`…aivencloud.com`) ya no se resuelve por DNS y la aplicación no arrancaba (P1001). Hacía falta otra base online gratuita, compatible con MySQL y accesible desde redes como eduroam.
- **Decisión:** se crea una instancia TiDB Cloud Starter (AWS Frankfurt, base `test`) y `DATABASE_URL` apunta a ella (`gateway01.eu-central-1.prod.aws.tidbcloud.com:4000`, usuario con prefijo `<prefijo>.root`, TLS con `sslaccept=strict`). Se aplicaron las 13 migraciones existentes con `npm run db:migrate`, `db:seed` (201 ciudades) y `db:seed-demo`. No hay cambios de esquema ni de código. Desaparece `backend/prisma/aiven-ca.pem`: el certificado de TiDB es público (Let's Encrypt) y no hay que descargarlo.
- **Alternativas:** volver a crear otro servicio Aiven (el motivo probable de la caída, inactividad, se repetiría); Postgres gratuito (obliga a cambiar el proveedor de Prisma y revisar migraciones); desplegar también el backend en la nube (más trabajo, fuera de alcance ahora).
- **Consecuencias:** los datos de la base de Aiven no se migran (el servicio ya no existía); la base nueva solo tiene el catálogo y los datos demo. Cada integrante pide al equipo la nueva `DATABASE_URL` (con contraseña) y actualiza su `.env`. La cuota gratuita es limitada (según la web de TiDB, 5 GiB y 50M Request Units al mes por instancia) y al agotarla rechaza conexiones hasta el mes siguiente; el cómputo puede escalar a cero y tardar en responder tras un rato parado. TiDB es compatible con MySQL pero no idéntico: las pruebas con MySQL real (`test:mysql`) siguen usando Docker. Esta decisión sustituye en lo que se refiere a Aiven a `2026-10-28-base-online-unica-para-desarrollo.md`, cuya idea (una única base online de desarrollo) sigue vigente.
