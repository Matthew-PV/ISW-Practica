## Estado

Los escenarios están definidos como especificaciones
de aceptación.

Objetivo 3: definición y documentación de escenarios.

Objetivos 4 y 5: implementación de los pasos y
automatización mediante Cucumber.

Objetivo 6: ejecución de regresión, validación de
interfaz y documentación de resultados.

## Criterios de ejecución

- Ejecutar las pruebas de forma reproducible.
- Aislar los datos utilizados durante las pruebas.
- Verificar tanto los casos correctos como los errores.
- Respetar los permisos y la visibilidad.
- Mantener las pruebas Jest existentes.
